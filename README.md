## 📌 Overview

This project performs an in-depth **Exploratory Data Analysis (EDA)** on a real-world dataset of 911 emergency calls from Montgomery County, Pennsylvania. The goal is to extract meaningful patterns — such as peak call times, most common emergency types, and geographic hotspots — using Python-based data science tools.

---

## 📊 Key Findings

- 🔥 **EMS** calls account for the highest volume, followed by Traffic and Fire
- 🕐 Call volume peaks between **3 PM – 6 PM** on weekdays
- 📅 Fridays have the highest average call volume across all categories
- 🗺️ Certain zip codes consistently show higher emergency activity

## 🗂️ Dataset

- **Source:** [Kaggle — 911 Calls Dataset](https://www.kaggle.com/datasets/mchirico/montcoalert)
- **Records:** ~660,000 911 call records
- **Features:** `lat`, `lng`, `desc`, `zip`, `title`, `timeStamp`, `twp`, `addr`, `e`
